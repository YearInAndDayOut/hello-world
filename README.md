# 六、新手避坑要点（非常重要）
1. **符号全部用英文半角**
`#` `*` `` ` ` `---` `()` `[]` 全部不能用中文符号，否则排版失效。
2. 标题 `#` 后面**必须加一个空格**，不然不识别
错误：`#Hello`
正确：`# Hello`
3. 反引号 `` ` `` 位置：键盘左上角，Esc 下面，不是单引号 '
4. 空行问题：模块之间空一行，排版更宽松好看，GitHub 渲染更美观。
5. 不要写太多杂乱内容，第一个项目**简洁干净 > 内容繁杂**。
